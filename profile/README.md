# aaen studios

A software *studio*. Tools that live on your machine.

OPEN SOURCE DESKTOP TOOLS · LOCAL-FIRST SOFTWARE

## The works

### 01 · kern

A desktop server manager for Windows, macOS and Linux. Register any project as a
server instance, extend it with plugins, and command the whole fleet from one
clean room.

`OPEN SOURCE · TAURI · DESKTOP` — [kern.aaenz.no](https://kern.aaenz.no) · [aaen-studios/kern](https://github.com/aaen-studios/kern)

### 02 · loom

A desktop app for AI chat and agents — providers, streaming with reasoning,
tools with permission modes, MCP servers, skills, subagents and a coding
workspace, on a Rust engine.

`OPEN SOURCE · TAURI · DESKTOP` — [aaen-studios/loom](https://github.com/aaen-studios/loom)

### 03 · galdr

A rune-encrusted GUI around FFmpeg. Raw media in, enchanted media out — convert,
compress, transcribe and cut without memorising a single command-line
incantation.

`OPEN SOURCE · TAURI · DESKTOP` — [aaen-studios/galdr](https://github.com/aaen-studios/galdr)

### 04 · yomion

A Japanese-learning app — typing trainer, FSRS flashcard engine, kanji path, and
an AI conversation partner. Local-first, with cloud sync when you want it.

`PRODUCT · WEB · LOCAL-FIRST` — [yomion.com](https://yomion.com)

## Open source, and offline by default

kern, loom and galdr are open source — read the code, open issues, fork them.
yomion runs in the browser and keeps your progress on your device; syncing is
optional.

`OPEN SOURCE · LOCAL-FIRST`
